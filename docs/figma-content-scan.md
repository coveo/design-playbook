## [291:67] 4.1.3 Shaping Workshop

- WHY?
- Shaping the problem and defining a path forward
- Most roadmap initiatives that involve design begin with a shaping workshop. It gives the whole team time to sit down and explore the problem and why it is a problem, discuss technical and design solutions to the problem, and define a clear path forward for kicking off the project. Smaller BAU design changes don’t need a shaping workshop. Shaping is different from normal specifications. We don’t start with all the stuff we want to do and then estimate how long it will take. We start by setting how much time we want to budget for this, then we reframe the problem, and mainly decide what we’re not going to do.
